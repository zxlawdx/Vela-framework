Leia o texto integral em [LICENSE](../LICENSE) e a FAQ oficial da

A MPL aplica o copyleft por arquivo: quem distribuir alterações
nos arquivos cobertos precisa disponibilizar o respectivo código
sob os termos da MPL. Aplicações que usam o framework podem
combinar arquivos próprios e proprietários separados, cumpridas
as condições que se aplicam ao código MPL distribuído.

**Atenção:** o gerador também copia arquivos de template deste
repositório para o projeto do usuário. Antes de distribuir uma
aplicação fechada construída a partir desses arquivos, confira
as obrigações dos arquivos copiados ou obtenha uma permissão
separada. O mero uso do runtime não impõe que a interface exiba
o nome do autor.
